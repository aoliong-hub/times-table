# 生活里的乘法

给小学一年级的乘法启蒙闯关游戏。从钟表、钱币、星期、日历这些孩子每天都碰得到的东西入手，
把「几个几」变成乘法：5 分钟一大格，3 大格就是 5 × 3 = 15 分钟。

一年级还没正式学乘法，所以全程只需要**点选**，不用输入、不用竖式；
每道题都先把「几份、每份几个」画出来，答完再显示加法展开、乘法式和口诀，
让孩子自己看出「连加就是乘法」。

## 五个关卡

| 关卡 | 生活场景 | 涉及的数 |
|------|----------|----------|
| ⏰ 钟表岛 | 一大格 5 分钟、一刻钟 15 分钟、1 小时 60 分钟 | 5、10、15、30、60 |
| 💰 钱币城 | 1 元 = 10 角、1 角 = 10 分、硬币纸币面值 | 2、3、5、10 |
| 📅 星期森林 | 一星期 7 天、上学 5 天、休息 2 天 | 2、3、4、5、7 |
| 🌞 日历山 | 一天 24 小时、一年 12 个月、一天三顿饭 | 3、4、9、12、24 |
| 🧺 生活百宝箱 | 一双袜子 2 只、一只手 5 指、小汽车 4 轮 | 2、4、5、6、8 |

每关 8 道题，题目按答案从小到大排，难度自然递增。

## 玩法与计分

- 四个选项点一个，答对基础 **10 分**
- **连对加分**：连对第 2 题起每题多 5 分，最多 +20，鼓励一口气答下去
- **一次答对再 +5**：想清楚再点比乱点划算
- 每题 **2 次机会**：第一次错了给生活常识提示（「钟面 1 大格 = 5 分钟」）再试一次；
  两次都错就公布答案，不卡住孩子
- 关末按得分率给 **1~3 星**（90% / 70% / 40%），成绩只在变好时覆盖，重玩失手不掉星

干扰项不是随机数，是照着一年级最容易犯的错生成的：少算一份、多算一份、把乘法当成加法、差 1、差 10。

## 目录结构

```
life-math/
├── miniprogram/           # 微信小程序（可直接用开发者工具打开上一级目录）
│   ├── core/              # 纯逻辑，不依赖 DOM / wx API，小程序与 H5 共用同一份
│   │   ├── questions.js   # 题库：生活场景模板、出题、干扰项、中文口诀
│   │   ├── game.js        # 一局游戏的计分引擎（连对、机会、星级）
│   │   └── progress.js    # 关卡进度存储（注入 storage 适配器）
│   ├── pages/
│   │   ├── home/          # 关卡地图
│   │   ├── play/          # 答题
│   │   └── result/        # 成绩
│   ├── app.js / app.json / app.wxss
│   └── sitemap.json
├── web/                   # 浏览器预览版，直接引用 miniprogram/core 的同一份逻辑
│   ├── index.html
│   ├── preview.js
│   └── preview.css
├── test/                  # Node 自测
├── project.config.json    # 小程序项目配置
└── README.md
```

`core/` 三个模块同时支持 `require`（小程序 / Node）和 `<script>` 全局（浏览器），
所以小程序版和预览版跑的是**同一套题库和计分规则**，改题库两边一起生效。

## 本地运行

浏览器预览（不需要微信开发者工具）：

```bash
# 直接打开也行，但用 http 起服务才能存进度（file:// 下部分浏览器禁用 localStorage）
cd life-math && python3 -m http.server 8080
# 打开 http://localhost:8080/web/index.html
```

跑测试：

```bash
node life-math/test/core.test.js        # 题库 + 计分引擎，13 项
node life-math/test/progress.test.js    # 进度存储，6 项

# 浏览器端冒烟测试（真实加载页面走完一整关），需要 jsdom：
cd /tmp && npm install jsdom --no-save
node life-math/test/web.smoke.js
```

## 发布到微信小程序

1. 微信开发者工具 → 导入项目，目录选 `life-math/`（`project.config.json` 已把
   `miniprogram/` 设为代码根目录）
2. AppID 填自己的；`touristappid` 是占位的测试号，只能本地预览，不能上传
3. 全部逻辑本地跑，不发网络请求，所以**不需要配置服务器域名**
4. 上传前在「详情 → 基本信息」把小程序类目选到「教育 → 在线教育」一类；
   面向未成年人的教育类小程序可能需要补充资质，按平台提示提交
5. 上传 → 在小程序后台提交审核 → 通过后发布

小程序侧用的都是基础能力（`wx.setStorageSync`、`wx.navigateTo`、`wx.vibrateShort`），
`vibrateShort` 做了存在性判断，低版本基础库不会报错。
